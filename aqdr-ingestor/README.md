# K-HEALTHinAIR Air Quality Data Repository (AQDR)

## Description

The K-HEALTHinAIR Air Quality Data Repository (AQDR) includes the subcomponents
in chagrge of the aggregation and maganementof the air quality information that
comes from the continuous monitoring devices.

### The Ingestor (`aqdr-ingestor`)

Module responsible for running all scheduled ETL pipelines. It performs the
automated ingestion of the data collected by the sensor devices into the
platform.
