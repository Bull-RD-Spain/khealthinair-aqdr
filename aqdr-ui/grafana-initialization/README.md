# K-HEALTHinAIR Grafana initialization

The Grafana backend exposes an HTTP API, the same API is used by the frontend to
do everything from saving dashboards, creating users and updating data sources.

The `grafana_client` package is automatically generated by the
[OpenAPI Generator](https://openapi-generator.tech) project:

- API version: 0.0.1
- Package version: 1.0.0
- Generator version: 7.6.0-SNAPSHOT
- Build package: org.openapitools.codegen.languages.PythonClientCodegen
For more information, please visit [https://grafana.com](https://grafana.com)

To regenerate the client, get the proper version openapi3.json definition (e.g.: https://raw.githubusercontent.com/grafana/grafana/refs/tags/v11.4.0/public/openapi3.json)
and from it, the [yaml](https://editor.swagger.io/?url=https://raw.githubusercontent.com/grafana/grafana/refs/tags/v11.4.0/public/openapi3.json)
Swagger > File > Convert and save as yaml (or `yq eval -P swagger.json > swagger.yaml`)

```bash
docker run --rm --volume /temp:/out \
docker.io/openapitools/openapi-generator-cli generate \
--generator-name python \
--input-spec /out/openapi3.yaml \
--output "/out" \
--package-name "khealthinair_grafana_client" \
--additional-properties="generateSourceCodeOnly=true,projectName=khealthinair,dateFormat=%d/%m/%Y"
```

you can run the following:

```python
from pprint import pprint

)

# The client must configure the authentication and authorization parameters
# in accordance with the API server security policy.
# Examples for each auth method are provided below, use the example that
# satisfies your auth use case.

# Configure API key authorization: api_key

# Uncomment below to setup prefix (e.g. Bearer) for API key, if needed
# configuration.api_key_prefix['api_key'] = 'Bearer'

# Configure HTTP basic authorization: basic

    username = os.environ["USERNAME"],
    password = os.environ["PASSWORD"]
)

# Enter a context with an instance of the API client
with grafana_client.ApiClient(configuration) as api_client:
    # Create an instance of the API class
    api_instance = grafana_client.AccessControlApi(api_client)
    team_id = 56 # int |
    add_team_role_command = grafana_client.AddTeamRoleCommand()

    try:
        # Add team role.
        api_response = api_instance.add_team_role(team_id, add_team_role_command)
        print("The response of AccessControlApi->add_team_role:\n")
        pprint(api_response)
    except ApiException as e:

```
